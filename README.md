# Snake

A classic Snake game that runs in the browser. Everything lives in a single `index.html` file, with no build step and no dependencies.

## Play

Open `index.html` in any modern browser.

Eat the red dots to grow. Each one adds a point and speeds you up a little. Running into a wall or your own tail ends the game.

## Controls

| Action | Keyboard | Touch |
| --- | --- | --- |
| Move | Arrow keys or `W` `A` `S` `D` | Swipe |
| Start / restart | `Space`, any move key, or the **Play** button | Tap **Play** |
| Pause / resume | `Space` | Not available yet |

## Best score

Your best score is saved in your browser's `localStorage`, so it carries over between visits on the same browser and device.
